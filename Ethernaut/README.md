# Ethernaut

Writeups de [Ethernaut](https://ethernaut.openzeppelin.com/), el wargame de smart contracts en Solidity de OpenZeppelin (testnet Sepolia). La plataforma no agrupa los niveles en categorías, así que acá se organizan por la vulnerabilidad o el concepto que enseña cada uno. Cada nivel conserva el número que tiene en la web.
