# Desafío 1 - Uso del inspector

## Solución

Primero le das en inspeccionar a la página y recargas. Ahí te van a llegar las peticiones y dentro del apartado de Network buscas en los Headers cuál dice X-CODE.

```
f2ca1bb6c7e907d06dafe4687e579fce76b37e4e93b7605022da52e6ccc26fd2
```

![Desafío 1 - Uso del inspector - imagen 1](images/01.png)

En el apartado de Elements buscas donde dice Hidden y ahí pegás ese código.

![Desafío 1 - Uso del inspector - imagen 2](images/02.png)

Actualizas la página y te devuelve el código ganador en la consola.

![Desafío 1 - Uso del inspector - imagen 3](images/03.png)
